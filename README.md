# Mantella Living World - OStim Expansion

OStim scenes for Mantella: live scene flows from your animation packs, scene talk, bystander comments, favourite positions and position requests.

| Folder | Contents |
|---|---|
| Source/Scripts | Papyrus sources |
| esp | Plugin as Spriggit YAML |
| tools | Flow generator, record generator |
| test | In-game test harness, log validator, offline simulator |

Requires: Mantella, OStim Standalone. Recommended: OSL Aroused with the Arousal module.
